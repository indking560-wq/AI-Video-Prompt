# AI Video Prompt

## AI Video Prompt Templates and Some Prompts

The `videoPromptData.ts` file contains two main collections:

1. **Video Prompt Templates** - Categorized templates for different video types:
   - Cinematic Movie Scene
   - Animation/Cartoon Sequence
   - Fashion Show Runway
   - Product Showcase/Advertisement
   - Nature Documentary
   - Travel Vlog/Adventure
   - Music Video Performance
   - Sports Highlight
   - News Report/Broadcast
   - Educational Explainer
   - Video Game Cinematic
   - Historical Drama

2. **Video Prompt Styles** - Detailed style parameters categorized by:
   - Visual Aesthetics
   - Genre & Theme Styles
   - Lighting Styles
   - Color Tones
   - Camera Movements
   - Camera Angles & Shot Types
   - Composition Techniques
   - Lens & Filter Effects
   - Cinematic Techniques
   - Animation & Medium Styles
   - Film Format & Texture
   - Editing & Transitions

## AI Video Prompt Generator

If you want to explore these templates and generate AI video prompts in a more interactive way, check out [AI Video Prompt Generator](https://videoprompt.online/), a specialized tool that structures and enhances video concept descriptions into technically precise prompts for AI video creation platforms.

It helps translate creative ideas into detailed instructions covering cinematography, scene composition, transitions, lighting, and stylistic elements that AI systems can accurately interpret and execute.

## Features

- **Template-Based Generation**: Enhance pre-built templates or develop custom ones
- **Natural Language Processing**: Convert simple descriptions into structured video prompts
- **Specialized Prompt Categories**: Support for cinematic scenes, marketing, animation, and more
- **Style Control System**: Fine-tune visual aesthetics across multiple parameters
- **Accessibility**: Designed for users of all experience levels


## How to use AI Video Prompt Generator

The AI Video Prompt Generator offers four approaches to prompt creation:

1. **Enhance Pre-built Templates**: Select a template and personalize key elements
2. **Develop Custom Templates**: Build your own structured prompt format
3. **Direct Scene Description**: Use natural language to describe your vision
4. **Hybrid Approach**: Combine templates with custom creative elements
